## ③ 지어내기 여부 — 판정 방법 (skills/08-review/spec.md 4장)
- forbidden_topics의 핵심 문구가 05-assemble.html 본문에 그대로 등장하면 fail.
- 키워드가 안 보여도, 문장 수가 많거나 서술이 구체적인 구간이 있으면 needs_human으로
  분류하고 그 구간을 issues에 위치와 함께 남긴다.
- 이 항목은 절대 pass만으로 끝내지 않는다 — 사람이 한 번 더 읽어야 할 구간이 있으면
  반드시 issues에 남긴다.
- status는 pass/fail/needs_human 중 하나만 쓴다(blocked는 이 판정에 해당하지 않는다).

## 공통 규칙 (모든 스킬 공통, 판정 시 참고)
1. 출처 표기 필수 — 카드 밖 자료도 가능하나 출처 명시. 개인 블로그·유튜브 금지
2. 쉬운 언어 — 청소년·외국인이 배경지식 없이 읽을 수 있게
3. 사실 vs 연출 구분 — AI 생성 이미지·영상엔 [연출] 표시
4. 지어내기 금지 — 카드에 없는 내용은 채우지 않음 (이번 판정의 핵심 규칙)
5. 충돌 시 병기 — 수치·날짜가 자료마다 다르면 '기록마다 다름'으로 나란히 표기
