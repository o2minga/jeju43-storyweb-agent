# 07-chatbot ‹안내원›

## ① 목표
검증된 사실 안에서만 답하는 유적지 전용 AI 안내원을 만든다. 환각(지어내기)과 정치적 편향을 배제하고, 모르는 것은 정직하게 모른다고 답하게 한다. 이 챗봇은 "새 정보를 창작하는 도구"가 아니라 "검증된 KB를 안내하는 창구"다.

## ② 맥락
- 입력:
  - 02-story의 `chatbot_kb[]` — Q&A 기초 데이터
  - `01-verify`의 `forbidden_topics`(지어내기 금지 목록) — 가드레일에 반영
- 출력: 05-assemble(조립공)이 **우측 하단 floating 버튼 → 모달**로 페이지에 끼워 넣는다.
- **실행 순서 주의**: 07은 05보다 **먼저** 완료되어야 한다. 05 조립 시점에 챗봇이 완성돼 있어야 모달을 바로 끼운다.

## ③ 범위 (포함 / 제외)
**포함**
- `chatbot_kb`를 RAG 검색용 지식베이스(JSON)로 구조화
- 환각 방지 가드레일(시스템 프롬프트) 설계
- `forbidden_topics`를 가드레일 거절 목록에 반영
- KB에 없는 질문 → "기록에 명시되지 않은 내용입니다" 정직 응답 규칙
- 우측 하단 floating 버튼 + 모달 UI JS 스크립트

**제외**
- 스토리 원고·타임라인 편집 (02 영역)
- KB에 담길 사실 자체의 검증 (01·02가 이미 검증함 — 07은 그 안에서만 동작)
- 이미지·오디오·웹 전체 조립 (03·04·05 영역)

## ④ 제약 (반드시 지킴)

### 1) 검증 사실 우선 (RAG 경계)
- 답변 근거는 **먼저 KB(검증된 사실) 안에서** 찾는다. 내부에 답이 있으면 KB로만 답한다.
- 각 답변은 KB 항목의 `source`를 근거로 유지한다.
- **확장**: 내부에 없거나 더 깊은 역사적 배경이 필요할 때만, `④-보강. 외부 검색·출처 보강 정책`에 따라 **신뢰 출처 + 인용 조건을 만족하는** 외부 배경지식을 `[AI 종합 연출 답변]`·`[출처]`와 함께 보강할 수 있다. 조건 미달 정보는 절대 쓰지 않는다.

### 2) 모르면 정직하게 (환각 0)
- KB로 답할 수 없는 질문은 반드시 **"기록에 명시되지 않은 내용입니다"** 로 답한다.
- 추측·개연성 있는 창작·"아마도"류 서술 금지.
- `forbidden_topics`에 해당하는 질문(예: 카드에 없는 생사 여부·책임 소재 등)도 같은 문구로 거절한다.

### 3) 중립·절제
- 정치적 편향, 특정 집단에 대한 가치판단, 과장된 감정 이입, 주관적 논평 금지.
- 차분하고 객관적인 안내 톤 유지(공통 규칙 2 — 쉬운 언어).

### 4) 충돌 사실은 병기
- 기록마다 값이 다른 사실은 하나로 확정하지 말고 "기록마다 다름"으로 나란히 안내한다.

### 5) 조립 연동 규격
- 모달은 **우측 하단 floating 버튼**으로 연다.
- 05-assemble이 스크립트를 그대로 삽입만 하면 동작하도록 자기완결적으로 출력한다(외부 의존 최소화).

### 6) 가드레일 테스트 항목은 kb[]에서 제외
- 02의 `chatbot_kb` 중 `note_for_07`이 붙은 항목(가드레일 테스트용)은 **`kb[]`에 넣지 않는다** — 그 질문 유형이 fallback으로 처리되도록 `guardrail`에만 반영한다.
- 혹시 실수로 `kb[]`에 포함시켜도, `agent/generate/step07_chatbot.py`의 코드가 `qa_id` 기준으로 강제 제거하는 최종 방어선이 있다(이 지침은 1차 방어선, 코드가 최종 방어선).

## ④-보강. 외부 검색·출처 보강 정책 (Search Grounding)
> ⚠ 이 정책은 ④-1의 "검증 사실 우선" 원칙을 **신뢰 출처 + 인용 조건 하에서만** 확장한다. 환각·미검증 정보는 여전히 금지.

**단계형 우선순위**
1. **내부 우선** — `KB.entries`에 답이 있으면 그대로 사용(검증된 사실).
2. **외부 보강** — 내부에 없거나 더 구체적 배경이 필요할 때만, 아래 두 경로에서만:
   - (a) **큐레이션 grounded**(`KB.grounded`) — 신뢰 기관이 공표한 *확립된 사실 + 인용*을 미리 담아둔 오프라인 안전 데이터.
   - (b) **라이브 검색 provider**(`window.CHATBOT_GROUNDING`) — 백엔드(서버의 Claude API + 웹 검색, **허용 도메인 한정**)가 주입될 때만 동작. 정적 클라이언트 단독으로는 실제 웹검색을 하지 않는다.
3. **폴백** — 못 찾으면 "기록에 명시되지 않았습니다"로 정직 응답.

**출처·라벨 의무 (Citation)**
- 외부 보강 답변엔 반드시 `[출처: 기관, 사료명 / URL]`을 문장 옆/하단에 명시.
- AI 가공·추론이 섞인 답변엔 `[AI 종합 연출 답변]` 라벨 부착.

**출처 채택 기준 (허용은 넓게, 차단은 명확히)** — 신뢰도 있는 기관 자료는 **자유롭게** 쓴다: 공공기관·공식 사료뿐 아니라 **검색·언론 기사**도 가능. 조건은 하나 — **어디서 왔는지 출처를 남길 것.**
- **차단(denylist, `KB.blockedSources`)**: **개인 블로그·유튜브** 및 이에 준하는 개인 UGC(SNS·개인 카페 등)만 배제.
- 참고용 신뢰 출처 힌트: `KB.allowedSources`(제주4·3평화재단·국사편찬위원회·진실화해위원회·제주4·3연구소·제주다크투어 등) — 게이트가 아니라 예시.

**환각 금지 (강제 규칙)**
- 보강 답변에 **출처가 없거나**(무출처) 인용이 **전부 차단 대상(개인 블로그·유튜브 등)**이면 → 답변을 **폐기하고 폴백**한다(미검증 배제).
- 민감·`forbidden_topics` 주제(발포 책임·특정인 생사 등)는 **외부 검색조차 하지 않고** 담담히 우회.
- 외부 보강 결과는 자동 공개하지 않으며, 외부 공개 전 함께공 감수를 거친다.

## ⑤ 출력 형식
이 호출에 함께 전달되는 JSON Schema(`Step07ChatbotOutput`)를 정확히 따른다 — `location_id` / `kb[]`(qa_id·question·answer·source·tags) / `guardrail`(system_prompt·fallback_answer·refuse_topics·conflict_note) / `widget`(launcher·modal_script_path·notes). `chatbot_kb`가 비면 `kb: []`로 두고, 챗봇은 모든 질문에 fallback으로만 답한다(억지로 지어내지 않음).

## ⑥ 성공 기준
- 내부 KB에 답이 있으면 KB(검증된 사실)로 우선 답한다
- 외부 보강 시 답변에 `[출처: 기관/사료·URL]`과 `[AI 종합 연출 답변]`이 반드시 붙는다
- 무출처이거나 인용이 전부 차단 대상(개인 블로그·유튜브)이면 답변을 폐기하고 fallback으로 정직 응답한다(환각/오답 0건)
- `forbidden_topics`·민감 주제는 외부 검색 없이 fallback으로 응답한다
- 정치적 편향·주관적 논평·과장된 감정 이입이 없다 / 충돌 사실이 병기된다
- floating 버튼으로 모달이 정상 구동되고, 05-assemble이 삽입만으로 연동된다

## 공통 규칙 (감점 방지선 — 8개 스킬 공통)
1. **출처 표기 필수** — 답변 근거는 KB의 `source`로 유지. 개인 블로그·유튜브 금지.
2. **쉬운 언어** — 청소년·외국인이 배경지식 없이 이해하도록.
3. **사실 vs 연출 구분** — 챗봇은 사실만 안내. 창작·연출 서술 금지.
4. **지어내기 금지** — KB에 없으면 "기록에 명시되지 않은 내용입니다".
5. **충돌 시 병기** — 기록마다 다른 값은 나란히 안내.
