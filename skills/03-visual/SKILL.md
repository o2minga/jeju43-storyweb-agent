# 03-visual ‹미술감독›

## ① 목표
장면에 맞는 이미지와 짧은 영상을 만들되, **잔인·사실적 재현을 피하고 문헌 이미지를 우선**하며, 모든 산출물의 **톤을 하나로 통일**한다. 이 작업의 가장 흔한 실패는 "결과물마다 스타일이 제각각 → 몰입 붕괴"이므로, 톤 통일이 핵심 과제다.

## ② 맥락
- 입력: `samples/02-story-output-example.json`의 `image_prompts_draft` 배열.
  각 항목은 `prompt_id` / `scene.{ko,en}` / `mood` / `note_for_03` 구조.
  `note_for_03`에 "재현 금지 게이트 적용 대상" 같은 지시가 담겨 오면 반드시 그 지시를 우선한다.
- 출력: 05-assemble(조립공)이 이미지·영상 블록으로 물려 쓴다. → `samples/03-visual-output-example.json` 형식으로 경로와 메타데이터를 넘긴다.
- 도구: **관리자 지정 이미지가 항상 최우선이다 — output 캐시보다도 먼저 확인한다.** 게이트를 통과·변환한 최종 프롬프트에 대해, 먼저 관리자가 외부 AI 도구로 직접 만들어 프로젝트 루트 `assets/{location_id}/{prompt_id}.png`(영상은 `.mp4`)에 넣어둔 파일이 있는지 확인하고, 있으면 그대로 채택해 **Cloudflare는 호출하지 않는다.** (output 캐시를 먼저 보면, 이미 한 번 처리된 장소에 관리자가 나중에 새 파일을 넣어도 캐시에 막혀 확인되지 않으므로 순서가 중요하다.) 관리자 지정 파일이 없을 때만 `output/{location_id}/assets/{prompt_id}.{ext}` 캐시를 보고(있으면 재사용, 재생성 비용 절약), 그것도 없을 때만 **Cloudflare Workers AI(flux-1-schnell)**를 호출해 실제 이미지를 자동 생성한다(`agent/generate/image_backend.py`). 03은 최종 경로에 파일이 있는지로 `status`(`ready`/`awaiting_manual_generation`)를 채우고, 아직 없는 것만 골라 `output/{location_id}/03-image-prompts-for-admin.md`에 정리한다.
- 톤 통일의 근거 문서는 같은 폴더의 `art-style.md`이며, **모든 생성 프롬프트에 자동 첨부**된다.
- (구현 메모) 이 우선순위는 파이프라인 훅(`agent/hooks/`)이 아니라 `visual_agent.py` 자체의 순서로 구현했다 — 훅 시스템이 03의 실행 흐름에 개입할 통로가 없기 때문(`PROGRESS.md`의 "파이프라인 훅" 절 참고).

## ③ 범위 (포함 / 제외)
**포함**
- `image_prompts_draft`의 각 프롬프트 초안을 재현 금지 게이트에 통과시켜 최종 생성 프롬프트로 변환
- 문헌 이미지(공공기관·기록물) 우선 탐색 → 있으면 AI 생성보다 우선 채택
- art-style.md 톤을 첨부한 AI 이미지 생성
- 필요 시 짧은(숏폼) 영상 생성 (정적 장면의 미세한 움직임 위주)
- 모든 AI 생성물에 `[연출]` 표시 메타데이터 부착
- 출력 메타데이터(JSON)를 05-assemble에 넘김
- 아직 안 만들어진(`awaiting_manual_generation`) 이미지만 골라 관리자용 프롬프트 문서(`03-image-prompts-for-admin.md`) 산출

**제외**
- 스토리 텍스트·타임라인·챗봇 KB 편집 (02·07 영역)
- 실제 웹페이지 조립 (05 영역)
- 오디오/BGM (04 영역)
- 실제 지도 라이브러리·좌표 처리 (06 영역)

## ④ 제약 (반드시 지킴)

### 1) 생성 전 '재현 금지 게이트' 통과 필수
어떤 프롬프트도 아래 게이트를 먼저 통과하지 않으면 생성 단계로 넘어갈 수 없다.

- **판정**: 프롬프트(초안 + `note_for_03`)에 아래 금지 요소가 있는지 검사한다.
  - 총살·처형·학살·구타 등 폭력 행위 장면
  - 시신·부상·피 등 피해 신체의 직접 묘사
  - 특정 실존 인물(피해자·생존자·가해자)의 식별 가능한 얼굴
- **처리**: 금지 요소가 감지되면 **직접 묘사를 생성하지 않고, 상징으로 우회 변환**한 뒤에만 통과시킨다. 원래 장면은 폐기하고 변환된 상징 장면만 생성한다.

**우회 변환 규칙 (구체 대응표)**

| 요청된(금지) 장면 | → 상징으로 우회 변환 |
|---|---|
| 총살·처형 장면 | **텅 빈 광장**, 아무도 없는 마당, 바닥에 **흩어진 신발**, 빈 의자 하나 |
| 시신·피해자 | 흰 천이 덮인 형체(신체 노출 없음), 놓인 꽃 한 송이, 빈 자리 위의 빛 |
| 폭력·구타·연행 | 부서진 문, 길게 늘어진 그림자, 열린 채 비어 있는 방 |
| 불타는 마을·방화 | 다 타고 굴뚝만 남은 터, 식은 재, 무너진 돌담 |
| 총소리·발포 순간 | 인물 없는 광장에 흐린 아침 공기, 새가 흩어지는 하늘 |
| 특정 인물의 얼굴 | **원경·뒷모습·실루엣**으로 처리하고 얼굴은 비특정(식별 불가)하게 |

- `note_for_03`에 "재현 금지 게이트 적용 대상"이 명시된 항목(예: `img-01`)은 무조건 이 변환을 거친다.
- 변환한 경우, 출력 메타데이터에 `gate: "converted"`와 변환 사유를 남긴다.

### 2) 절대 생성 금지 (예외 없음)
- 잔인한 피해 장면의 직접 묘사
- 실존 인물(피해자·생존자·가해자)의 얼굴 복제·재현
- 위 둘은 우회 변환으로도 대체가 불가능하면 **생성 자체를 포기**하고 문헌 이미지 또는 상징 이미지로 대체한다.

### 3) 문헌 이미지 우선
- AI 생성 전에 공공기관·공식 사이트·기록물의 **문헌 이미지**가 있는지 먼저 확인한다.
- 있으면 AI 생성보다 우선 채택하고, 출처를 반드시 표기한다(개인 블로그·유튜브 금지).
- 문헌 이미지는 실제 기록이므로 `[연출]` 표시를 붙이지 않는다(사실 자료).

### 4) art-style 자동 첨부로 톤 통일
- 모든 AI 생성 요청 프롬프트에 같은 폴더의 `art-style.md`(화풍·채도·색감·분위기)를 **자동으로 덧붙인다.**
- art-style.md 파일만 교체하면 전체 톤이 일괄 변경되도록 설계한다(프롬프트에 스타일을 하드코딩하지 않는다).

### 5) 모든 AI 생성물에 `[연출]` 표시
- AI로 만든 모든 이미지·영상에는 `[연출]`(AI 생성) 표시를 붙인다.
- 출력 메타데이터에 `is_ai_generated: true`, `label: "[연출]"`을 넣어 05-assemble이 캡션에 노출하게 한다.
- 문헌 이미지(실제 기록)와 절대 혼동되지 않게 한다.

## ⑤ 출력 형식
`samples/03-visual-output-example.json` 형식으로 산출한다. 각 자산은 다음 필드를 갖는다.

```json
{
  "location_id": "gwandeokjeong",
  "assets": [
    {
      "asset_id": "vis-01",
      "source_prompt_id": "img-01",
      "type": "image",                 // "image" | "video" | "archival"
      "path": "output/gwandeokjeong/assets/img-01.png",
      "is_ai_generated": true,
      "label": "[연출]",               // AI 생성물만. 문헌 이미지는 "" 또는 생략
      "gate": "converted",             // "passed" | "converted" | "skipped"
      "gate_reason": "총살 장면 요청 → 텅 빈 광장 + 흩어진 신발로 우회 변환",
      "final_prompt": "art-style 첨부된 최종 생성 프롬프트",
      "source": "AI 생성 (Cloudflare Workers AI, flux-1-schnell)", // 미설정/실패 시 "AI 생성 (관리자가 외부 도구로 직접 생성)" 또는 "AI 생성 (관리자 생성 대기 중)", 문헌 이미지는 실제 출처 표기
      "caption": { "ko": "이른 봄, 사람이 빠져나간 관덕정 마당 [연출]", "en": "" },
      "status": "ready" // "awaiting_manual_generation" | "ready" — output/{location_id}/assets/{prompt_id}.{ext}에 파일이 있는지로 결정
    }
  ]
}
```

- `path`는 실제 파일이 최종적으로 자리잡는 곳(`output/{location_id}/assets/{prompt_id}.{png|mp4}`)과 정확히 같다. 관리자가 수동으로 만들 때는 프로젝트 루트 `assets/{location_id}/{prompt_id}.{png|mp4}`에 넣으면 이 자리로 자동 복사된다.
- 문헌 이미지는 `type: "archival"`, `is_ai_generated: false`, `label` 없음, `source`에 실제 출처.
- 생성을 포기한 항목은 `gate: "skipped"`로 남기고 대체 자산을 함께 표기한다.

## ⑥ 성공 기준
- 잔인·재현 이미지 **0건** (게이트를 우회하지 않은 폭력·피해 직접 묘사가 하나도 없음)
- 실존 인물 얼굴 복제 **0건**
- 문헌 이미지가 있으면 AI보다 우선 사용됨
- 여러 산출물이 "같은 손이 만든 것"처럼 톤이 일관됨 (art-style 자동 첨부 확인)
- 모든 AI 생성물에 `[연출]` 표시가 붙음
- 출력 JSON이 05-assemble이 바로 읽을 수 있는 형식으로 나옴
- `status`가 `output/{location_id}/assets/{prompt_id}.{ext}`의 실제 파일 존재 여부와 항상 일치하고, `ready`가 아닌 항목은 전부 `03-image-prompts-for-admin.md`에 목록화됨

## 공통 규칙 (감점 방지선 — 8개 스킬 공통)
1. **출처 표기 필수** — 카드 밖 자료도 가능하나 출처 명시. 개인 블로그·유튜브 금지. (문헌 이미지 채택 시 출처 필수)
2. **쉬운 언어** — 캡션·설명은 청소년·외국인이 배경지식 없이 읽을 수 있게.
3. **사실 vs 연출 구분** — AI 생성 이미지·영상엔 반드시 `[연출]` 표시. 기록 사진과 혼동 금지.
4. **지어내기 금지** — 카드에 없는 장면(특정 인물의 생사, 발포 위치 등)을 이미지로 만들어내지 않는다.
5. **충돌 시 병기** — 기록마다 다른 사실은 이미지로 하나를 확정 짓지 않는다(상징·분위기로 처리).

- 톤 근거: `skills/03-visual/art-style.md`
