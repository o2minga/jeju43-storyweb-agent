# 06-map ‹현관문›

## ① 목표
여러 유적지를 제주 지도 하나로 묶는 **첫 화면(인덱스)**을 만든다. **Leaflet + OpenStreetMap** 실제 지도 위에 장소 좌표(위경도)를 마커로 찍고, **카드를 추가하면 장소가 늘어나는 확장 구조**를 보여준다. 장소가 하나여도 "확장되는 구조"를 증명하는 게 목적이다.

## ② 맥락
- 입력: 여러 장소의 05-assemble 산출을 모은 목록. 각 항목:
  `location_id` / `name.{ko,en}` / `coord.{lat,lng}` / `one_liner.{ko,en}` / `thumbnail` / `page_link`(05가 만든 .html 경로)
  → `samples/06-map-input-example.json` 형식.
  전체 흐름 타임라인 섹션을 위해 `timeline_events`(02-story 산출을 그대로 복사, 선택 항목)도 함께 받는다.
- 출력: 지도 인덱스 `.html` 한 장(사이트 첫 화면). 마커 팝업의 링크 클릭 → 해당 장소의 05 스크롤 페이지로 이동.
  모든 장소의 `timeline_events`를 날짜순으로 합친 "전체 타임라인" 섹션도 함께 렌더링한다(장소를 추가하면 자동으로 합류).
- 아키텍처: `AGENT-SPEC.md` 5장 기준 **C그룹(조립형)** — Claude 호출 없이 **코드 템플릿**으로 데이터를 끼워 넣는다.
- 실행 순서: 06은 05 결과를 링크만 하므로 가장 마지막이어도 무방하다.

## ③ 범위 (포함 / 제외)
**포함**
- Leaflet 지도에 장소 좌표(위경도)로 **마커** 렌더링 (좌표→픽셀 변환 불필요 — 라이브러리가 처리)
- 마커 팝업(이름 · 한 줄 소개 · 대표 이미지 · 05 페이지 링크)
- 마커 → 05 스크롤 페이지 링크 연결
- 확대 · 축소 · 이동(팬) 인터랙션 (Leaflet 기본 제공)
- 장소가 여러 개면 전체가 보이도록 자동 맞춤(fitBounds), 1개면 해당 위치로 이동
- 카드(장소) 추가만으로 마커가 늘어나는 구조

**제외**
- 개별 장소 스토리 페이지 제작 (05 영역)
- 좌표 자체의 사실 검증 (01·카드 영역)

## ④ 제약 (반드시 지킴)

### 1) 키 없는 오픈소스 지도
- **Leaflet(지도 UI) + OpenStreetMap(타일)** 조합. API 키·도메인 등록이 필요 없다.
- 지도 타일 로딩에는 인터넷이 필요하다. (라이브러리는 CDN에서 로드: `unpkg.com/leaflet`)
- 좌표는 위경도 그대로 `L.marker([lat, lng])` 로 찍으므로 좌표→픽셀 변환식·베이스 이미지가 필요 없다.

### 2) 마커 위치 = 실제 좌표
- 마커는 지리 좌표(위경도)에 묶이므로 확대·축소·이동해도 지도상 같은 위치에 고정된다(Leaflet이 보장).

### 3) 확장 구조
- 입력 목록에 장소를 추가하면 코드 수정 없이 마커가 늘어나야 한다.
- 장소가 1개여도 정상 렌더링된다(빈 목록이면 "등록된 장소가 없습니다" 안내만 표시, 지어내지 않음).

## ⑤ 출력 형식
- 산출물: `output/index.html`(또는 지정 경로) — 자기완결 정적 페이지.
- 입력 계약은 `samples/06-map-input-example.json` 형식을 따른다.

```json
{
  "places": [
    {
      "location_id": "{장소_식별자}",
      "name": {"ko": "{장소명}", "en": ""},
      "coord": {"lat": 0.0, "lng": 0.0},
      "one_liner": {"ko": "{한 줄 소개}", "en": ""},
      "thumbnail": "{대표 이미지 경로}",
      "page_link": "{05가 만든 스토리 .html 경로}",
      "timeline_events": [
        {
          "event_id": "{tl-01}",
          "date": "{YYYY 또는 YYYY-MM-DD}",
          "title": {"ko": "{사건명}", "en": ""},
          "description": {"ko": "{설명}", "en": ""},
          "source": "{02-story에서 온 출처}"
        }
      ]
    }
  ]
}
```

- `timeline_events`는 02-story 산출을 그대로 복사한 것으로, 06에서 새로 지어내지 않는다. 없으면(빈 배열/누락) 그 장소는 전체 타임라인에서 조용히 제외된다.

- 좌표(`coord.lat/lng`)를 그대로 `L.marker` 에 넘기므로 별도의 지도 이미지 메타(`map` 블록)는 필요 없다.
- `places`가 비면 지도만 표시하고 "등록된 장소가 없습니다" 안내만 둔다(마커 지어내지 않음).

## ⑥ 성공 기준
- 마커 팝업의 링크 클릭 시 해당 장소의 05 스토리 페이지로 이동한다
- 확대·축소·이동이 동작한다 (Leaflet 기본)
- 마커가 실제 좌표(위경도) 위치에 고정된다
- **카드(장소) 추가만으로 마커가 늘어난다**
- API 키·도메인 등록 없이 동작한다(지도 타일 로딩에는 인터넷 필요)

## 공통 규칙 (감점 방지선 — 8개 스킬 공통)
1. **출처 표기 필수** — 미리보기에 쓰는 대표 이미지가 문헌 자료면 출처 유지, AI 생성이면 `[연출]` 표시 유지(05에서 온 표기 존중). 개인 블로그·유튜브 금지.
2. **쉬운 언어** — 한 줄 소개는 청소년·외국인이 이해할 수 있게.
3. **사실 vs 연출 구분** — 썸네일이 AI 생성물이면 `[연출]` 표시가 유지되게 한다.
4. **지어내기 금지** — 입력에 없는 장소·좌표를 만들지 않는다.
5. **충돌 시 병기** — 좌표·정보가 자료마다 다르면 임의 확정하지 않는다(입력이 병기했으면 그대로).

## 입력 예시 / 출력 예시
- 입력: `samples/06-map-input-example.json` (여러 장소의 05 결과 목록)
- 출력: `output/index.html` (지도 인덱스 첫 화면)
- 구현 상세(Leaflet 마커·팝업·fitBounds): `skills/06-map/spec.md` 4장
