# skills/01-verify/spec.md — 01-verify 스킬 상세 스펙 ‹문지기›

> 이 문서는 `AGENT-SPEC.md`의 일반 원칙 위에서 01-verify만의 세부 규칙을 정의한다.
> **특정 유적지의 실제 역사적 사실이나 문장은 예시로도 포함하지 않는다.** 아래 예시는 전부 플레이스홀더다 — 어떤 카드가 들어와도 이 문서 내용은 그대로 유지되어야 한다.

---

## 1. 목표

카드가 어떤 유적지의 이야기이든, 그 안에서 **출처가 있는 사실만** 골라내고, **카드가 하지 말라고 명시한 것들**을 빠짐없이 목록화한다. 이 스텝의 결과가 이후 7개 스텝 전부의 기반이 된다.

---

## 2. 입력 — 카드의 일반 구조

`AGENT-SPEC.md` 1·2장에서 정의한 표준 섹션 패턴을 그대로 따른다. 요약하면:

- 카드는 섹션별로 구성되어 있으며, **모든 섹션이 항상 존재한다는 보장은 없다** → 방어적으로 파싱한다 (없으면 건너뛴다)
- 출처는 3가지 형식(인라인 브래킷 / 표 전용 컬럼 / 원문 그대로 인용) 중 하나 이상으로 등장한다
- `⚠ 주의` 성격의 섹션(이름은 카드마다 다를 수 있음 — "주의", "금지사항", "유의사항" 등)이 있다면 **가장 먼저·가장 정확하게** 처리해야 한다

---

## 3. 범위 (포함 / 제외)

**포함**
- 카드 파싱 (섹션 유무 확인 → 있는 섹션만 항목별 추출)
- 각 사실에 출처가 붙어 있는지 확인
- 자료 간 충돌 검사 → 병기 처리
- 지어내기 금지 항목 원문 그대로 목록화
- 카드 내용이 부족할 때만 추가 검색 (충분하면 검색 생략)

**제외**
- 이야기 작성 (02 담당)
- 이미지·영상 관련 판단 (03 담당)

---

## 4. 일반 처리 원칙 (카드 내용과 무관하게 항상 적용)

이 원칙들은 특정 카드에서 발견된 게 아니라, **어떤 카드든 발생할 수 있는 패턴**이므로 항상 확인한다.

1. **"정보가 없다 / 기록되지 않았다"는 서술 자체는 유효한 검증된 사실이다.**
   빠진 정보로 착각해서 `forbidden_topics`에 넣거나 누락시키지 않는다. `verified_facts`에 "~에 대한 기록은 남아있지 않음"처럼 그대로 남긴다.

2. **`⚠ 주의` 섹션에 "카드 밖의 다른 통설/이야기가 있지만 이 카드엔 없다"는 식의 예시가 있다면**, 그 예시 내용을 사실처럼 서술하지 않는다. 예시 자체는 "이런 유형은 이 카드 자료에 없으므로 쓰지 않는다"는 금지 목록 항목으로만 취급한다.

3. **두 가지를 반드시 구분해서 별도 필드에 담는다** — 겉보기엔 비슷해 보이지만 처리 방식이 다르다.
   - **`conflicts`** = 자료마다 서로 다른 값이 있어서 하나를 고를 수 없는 경우 → "기록마다 다름"으로 병기
   - **`precision_guardrails`** = 값 자체는 하나로 확인되지만, 뭉뚱그려 서술하면 안 되는 경우 (예: 여러 하위 항목이 합쳐진 값을 전부 같은 곳/같은 대상으로 단정하면 안 되는 경우) → 정확한 표현 규칙 명시

   이 두 필드는 항상 둘 다 스키마에 존재해야 하며, 해당하는 내용이 없으면 빈 배열(`[]`)로 둔다. 하나로 합쳐서 담지 않는다.

4. **카드 전체에 적용되는 공개 제한 플래그**(예: "감수 전 외부 공개 금지" 같은 문구)가 있다면, 개별 사실이 아니라 **문서 전체의 메타데이터**로 취급하고 이후 모든 단계(05·08)까지 그대로 전달한다.

5. **`sources[]`의 `used_for_en`·`ref_en`도 한국어(`used_for`·`ref`)와 동일한 방식으로 실제로 채운다** — 구조상 자리만 남기고 비워두지 않는다. `ref_en`은 05-assemble이 영문 문단 안 출처 인용("[Source: ...]")에, `used_for_en`은 영문 출처 목록에 그대로 쓴다.

---

## 5. 제약

- 추가 검색은 카드가 불충분할 때만 수행하며, 공공기관·공식사이트·기사·논문·지도만 채택 (개인 블로그·유튜브 금지)
- 추가 자료는 반드시 출처를 함께 저장
- "출처 원문" 섹션에 있는 인용문은 **한 글자도 수정하지 않는다**
- 카드의 지어내기 금지 항목은 절대 확정 서술하지 않는다

---

## 6. 출력 형식 (JSON 스키마)

아래 값은 전부 예시(플레이스홀더)다. 실제 실행 시 카드 내용에 맞게 채워진다.

```json
{
  "location_id": "{장소_식별자}",

  "verified_facts": [
    {
      "fact_id": "f-01",
      "text": "{카드에서 추출한 사실 문장}",
      "source": {"type": "card", "ref": "{카드에 명시된 출처명}"}
    },
    {
      "fact_id": "f-02",
      "text": "{'~에 대한 기록은 확인되지 않음' 같은, '정보 없음'도 유효한 사실로 남긴 예}",
      "source": {"type": "card", "ref": "{출처명}"},
      "note": "정보 부재 자체가 검증된 사실 — forbidden_topics 아님"
    }
  ],

  "sources": [
    {
      "ref": "{출처명}",
      "used_for": "{이 출처가 어디에 쓰이는지}",
      "used_for_en": "{used_for의 영문 번역 — 한국어와 동일한 방식으로 실제로 채움}",
      "ref_en": "{ref(출처명)의 영문 번역 — 영문 문단 안 인용(\"[Source: ...]\")에 쓰임}"
    }
  ],

  "citation_guide": [
    {"format": "{카드에 인용 형식 안내가 있다면 그대로}", "when": "{어떤 경우에 이 형식을 쓰는지}"}
  ],

  "verbatim_quotes": [
    {
      "id": "q-01",
      "text": "{원문 그대로, 절대 수정하지 않음}",
      "source": "{출처}",
      "modification_allowed": false
    }
  ],

  "forbidden_topics": [
    "{카드의 주의/금지 섹션 문구를 요약하지 않고 원문 그대로}"
  ],

  "conflicts": [
    {
      "topic": "{자료마다 값이 다른 항목}",
      "values": [
        {"value": "{값 1}", "source": "{출처1}"},
        {"value": "{값 2}", "source": "{출처2}"}
      ],
      "resolution": "기록마다 다름 — 병기"
    }
  ],

  "precision_guardrails": [
    {
      "topic": "{뭉뚱그리면 안 되는 항목}",
      "rule": "{정확히 어떻게 표기해야 하는지}"
    }
  ],

  "publication_flag": {
    "internal_only": true,
    "note": "{카드에 공개 제한 문구가 있다면 그대로, 없으면 false/null}"
  }
}
```

> 카드에 특정 섹션(예: 현장 안내판 원문)이 없으면, 해당 필드는 빈 배열 `[]`로 두고 **절대 내용을 지어내서 채우지 않는다.**

---

## 7. 성공 기준

- [ ] 카드의 모든 사실에 출처가 매칭되어 있다
- [ ] 카드에 등장하는 출처 표기 패턴(인라인/표 컬럼/원문 인용) 중 있는 것은 전부 파싱됐다
- [ ] 주의/금지 섹션이 요약·순화 없이 원문 그대로 `forbidden_topics`에 반영됐다
- [ ] "정보 없음"류 서술이 금지 목록에 잘못 들어가지 않았다
- [ ] `verbatim_quotes`의 텍스트가 카드 원문과 한 글자도 다르지 않다
- [ ] 카드에 없는 섹션은 억지로 채우지 않고 빈 값으로 처리됐다 (방어적 파싱 확인)
- [ ] `publication_flag`가 출력에 포함되어 있다
- [ ] 추가 검색을 했다면 전부 출처가 붙어 있다
- [ ] `sources[]`의 `used_for_en`·`ref_en`이 빈 문자열로 남지 않고 실제 영문 번역으로 채워졌다
- [ ] **(중요) 이 스킬을 다른 유적지의 카드로 실행해도 위 기준을 동일하게 만족한다** — 관덕정 카드에서만 통하는 규칙이 섞여 있지 않은지 최종 점검
