## 2. 입력

- `samples/02-story-output-example.json`의 `chatbot_kb[]` — 각 항목:
  - `qa_id` / `question.{ko,en}` / `answer.{ko,en}` / `source`
  - `note_for_07`(있을 수 있음) — 가드레일 테스트용 지시(예: "이 유형 질문은 fallback으로 답하라")
- `01-verify` 출력의 `forbidden_topics[]` — 지어내기 금지 목록. 가드레일의 거절 목록으로 반영.
- (있으면) `conflicts_carried_forward` / `precision_guardrails_applied` — 병기·정밀도 안내에 활용.

> `chatbot_kb`가 비어 있거나 없으면 `kb: []`로 두고, 챗봇은 모든 질문에 fallback으로만 답한다(방어적 처리, 지어내지 않음).

## 3. 범위 (포함 / 제외)

**포함**
- `chatbot_kb`를 검색 매칭 가능한 KB JSON으로 구조화(태그·키워드 부여)
- 환각 방지 가드레일(시스템 프롬프트) 작성
- `forbidden_topics`를 거절 목록에 반영
- floating 버튼 + 모달 UI JS(자기완결)

**제외**
- KB에 담기는 사실 자체의 검증(01·02가 수행) — 07은 그 경계 안에서만 동작
- 스토리·이미지·오디오·조립(02·03·04·05)

## 4. 가드레일 판정 로직 (카드 내용과 무관하게 항상 적용)

사용자 질문이 들어오면 아래 순서로 판정한다.

1. **거절 판정(refuse) 우선**: 질문이 `forbidden_topics` 또는 `note_for_07`가 지정한 거절 유형(발포 책임·특정인 생사 등)에 해당하면, **외부 검색조차 하지 않고** 즉시 fallback 문구로 답한다.
2. **KB 매칭 검색(내부 우선)**: 질문을 KB 항목의 `question`/`tags`와 매칭. 매칭되면 `answer`를 근거(`source`)와 함께 답한다.
3. **외부 보강(grounding)**: 내부에 없거나 더 깊은 배경이 필요하면, 신뢰 기관·공공기관·언론 기사 등 **출처를 남길 수 있는 자료**를 가져온다 — 큐레이션 `grounded` 또는 라이브 provider. 단 **무출처이거나 개인 블로그·유튜브(개인 UGC, `blockedSources`)면 폐기**한다. 보강 답변엔 `[출처: 기관/사료·URL]`과 `[AI 종합 연출 답변]` 라벨을 붙인다.
4. **미매칭(fallback)**: 위에서 못 찾으면 반드시 **"기록에 명시되지 않은 내용입니다."** 로 답한다. 추측·"아마도"류 금지.
5. **충돌 병기**: 답이 여러 값을 가진 사실(conflict)이면 하나로 확정하지 말고 "기록마다 다름"으로 나란히 안내한다.
6. **중립 유지**: 어떤 경로든 정치적 편향·가치판단·과장된 감정 이입·주관적 논평을 넣지 않는다.

> 핵심 불변식: **답변은 (a) 검증된 KB, 또는 (b) 출처를 남긴 외부 정보(신뢰 기관·공공기관·기사 등, 개인 블로그·유튜브 제외) — 이 둘에서만** 생성한다. 무출처·미검증·차단 대상 정보는 쓰지 않으며, 모든 답변의 근거는 KB 항목 또는 명시된 인용으로 추적 가능해야 한다. (상세: SKILL.md ④-보강)

---

## 5. 제약

- 답변 근거는 **검증된 KB 우선**. 외부 보강은 **출처를 남길 수 있는 신뢰 자료(기관·공공기관·기사 등)면 자유롭게** 허용하되, 무출처·개인 블로그·유튜브(개인 UGC, `blockedSources`)면 폐기(미검증 배제).
- 외부 보강 답변엔 `[출처: 기관/사료·URL]`·`[AI 종합 연출 답변]` 의무.
- 거절 대상·민감 주제 질문은 외부 검색 없이 100% fallback 문구.
- 정치 편향·주관 논평·과장된 감정 이입 금지. 기록마다 다른 값은 병기.
- 라이브 웹검색은 서버(백엔드 Claude API + 웹 검색, 허용 도메인 한정)에서 수행하고, 정적 클라이언트는 `window.CHATBOT_GROUNDING` 훅으로 연결. 외부 보강 결과는 함께공 감수 전 외부 공개 금지.
- 모달은 우측 하단 floating 버튼으로 열고, 05가 삽입만 하면 동작하도록 외부 의존을 최소화한다.
- `note_for_07`이 붙은 `chatbot_kb` 항목(가드레일 테스트용)은 `kb[]`에 포함하지 않는다 — fallback 처리로만 `guardrail`에 반영한다. 혹시 모델이 실수로 포함시켜도 `agent/generate/step07_chatbot.py`가 `qa_id` 기준으로 코드로 강제 제거하는 최종 방어선이 있다(재현성 확보 — 08 검수의 "AI 챗봇 지식베이스 일치 여부" 항목이 이 누출을 fail로 잡아낸다).

## 6. 출력 형식 (JSON 스키마)

아래 값은 전부 예시(플레이스홀더)다. 실제 실행 시 카드·KB 내용에 맞게 채워진다.

```json
{
  "location_id": "{장소_식별자}",
  "kb": [
    {
      "qa_id": "kb-01",
      "question": {"ko": "{질문}", "en": ""},
      "answer": {"ko": "{KB 근거 답변}", "en": ""},
      "source": "{근거 출처}",
      "tags": ["{검색 매칭용 키워드}"]
    }
  ],
  "guardrail": {
    "system_prompt": "{검증 사실 내 답변·환각 금지·중립·정직 거절 규칙을 담은 지시문}",
    "fallback_answer": {"ko": "기록에 명시되지 않은 내용입니다.", "en": ""},
    "refuse_topics": ["{01의 forbidden_topics를 그대로 반영}"],
    "conflict_note": "기록마다 다른 값은 병기하여 안내"
  },
  "widget": {
    "launcher": "floating-bottom-right",
    "modal_script_path": "output/{location_id}/chatbot-modal.js",
    "notes": "05-assemble이 삽입만 하면 동작하는 자기완결 스크립트"
  }
}
```

- `chatbot_kb`가 비면 `kb: []`, 가드레일은 유지(모든 질문 fallback).
- `refuse_topics`는 01의 `forbidden_topics`를 요약·순화하지 않고 그대로 반영한다.

## 7. 성공 기준

- [ ] 검증 근거(KB) 내에서만 일관되게 답한다
- [ ] KB 밖 질문·`forbidden_topics` 질문에 100% fallback 문구로 응답한다(환각/오답 0건)
- [ ] `note_for_07`가 지정한 거절 유형 질문이 fallback으로 처리된다
- [ ] 정치적 편향·주관적 논평·과장된 감정 이입이 없다
- [ ] 충돌 사실이 병기된다
- [ ] floating 버튼으로 모달이 구동되고, 05-assemble이 삽입만으로 연동된다
- [ ] `chatbot_kb`가 비었을 때 억지로 답을 지어내지 않는다(방어적 처리)
- [ ] **(중요) 다른 유적지 카드로 실행해도 위 기준을 동일하게 만족한다** — 특정 장소에서만 통하는 규칙이 섞이지 않았는지 최종 점검
