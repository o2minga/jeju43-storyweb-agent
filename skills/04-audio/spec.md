# skills/04-audio/spec.md — 04-audio 스킬 상세 스펙 ‹음향감독›

> 이 문서는 `AGENT-SPEC.md`의 일반 원칙 위에서 04-audio만의 세부 규칙을 정의한다.
> **특정 유적지의 실제 역사적 사실이나 문장은 예시로도 포함하지 않는다.** 아래 예시는 전부 플레이스홀더다 — 어떤 카드가 들어와도 이 문서 내용은 그대로 유지되어야 한다.
> 실행용 요약 지시문은 `SKILL.md`에 있다. 이 문서는 TTS·BGM·싱크·출력 스키마의 상세를 담는다.

---

## 0. 아키텍처 위치 (지금 단계)

`AGENT-SPEC.md` 5장 기준 **04-audio는 B그룹(미디어 생성형)** 이다.

- 지금은 실제 mp3를 만들지 않고, **정해진 출력 스키마를 채운 placeholder 결과를 리턴하는 함수**로만 구현한다.
- 나중에 TTS·음악 생성 API 키가 생기면 **함수 내부만 교체**하면 되도록, 입출력 스키마는 지금 확정해 둔다.
- 이 spec의 핵심은 "무엇을 어떤 모양으로 내보내는가"와 "어떤 제약을 지키는가"이다. 실제 음색·모델 파라미터는 범위 밖.

---

## 1. 목표

카드가 어떤 유적지이든, 02 원고를 차분·객관 톤으로 정확히 낭독한 TTS와 절제된 BGM을, 05 오디오 플레이어에 바로 붙는 에셋 메타데이터로 변환한다.

---

## 2. 입력 — 02-story 출력의 일부

- `story.{intro,development,closing}.{ko,en}` — 낭독 대상 원고. **ko만 사용**, en은 자리만.
- `timeline_events[]`(있으면) — 싱크 타임라인 구성 참고.
- `location_id` / `location_name` — 파일 경로·식별.

> `story`가 비어 있거나 ko가 없으면 narration을 만들지 않고 해당 필드를 `null`/빈 값으로 둔다(방어적 처리, 지어내지 않음).

---

## 3. 범위 (포함 / 제외)

**포함**
- 02 원고(ko) → TTS 음성 생성(지금은 placeholder 경로 리턴)
- 원고에서 고유명사·용어를 추출해 발음 사전 구성·적용
- 로열티 프리/자체 생성 BGM 매칭 + 음량 밸런싱
- 문단(및 필요 시 문장) 단위 싱크 타임라인 산출
- 05 오디오 플레이어용 에셋 패키지 메타데이터 출력

**제외**
- 원고 편집·번역(02), 이미지·영상(03), 조립(05), 챗봇(07)
- 실제 음색·속도·프레임 튜닝(placeholder 범위 밖)

---

## 4. 처리 로직 (카드 내용과 무관하게 항상 적용)

1. **발음 사전 구성(추출식)**: 특정 카드 용어를 하드코딩하지 않는다. 원고에서 고유명사·연도·역사 용어 후보를 추출해 `{term, reading}` 쌍으로 만든다. 사람이 검수·보정할 수 있도록 목록으로 남긴다.
2. **TTS 생성**: 발음 사전을 적용해 ko 원고를 차분·객관 톤으로 읽는다. 감정 과잉·극적 억양 금지.
3. **BGM 선택**: 로열티 프리 또는 자체 AI 생성만. 상업용 무단 사용 금지. 라이선스/출처를 메타데이터에 남긴다.
4. **밸런싱**: BGM 음량을 낭독보다 충분히 낮춘다(`volume_relative_to_narration` ≤ 약 0.3 권장). 음성 명료도 우선.
5. **싱크 타임라인**: 최소 문단(intro/development/closing) 단위로 `start_sec`/`end_sec`를 부여한다. 05가 스크롤·하이라이트에 쓸 수 있게 한다.
6. **충돌 병기 유지**: 원고가 "기록마다 다름"으로 병기한 부분은 낭독도 그대로 병기해 읽는다(임의 확정 금지).

> 핵심 불변식: **원고에 없는 문장을 낭독에 추가하지 않는다.** 오디오는 02 원고의 음성 버전일 뿐, 새 내용을 만들지 않는다.

---

## 5. 제약

- 차분·객관 톤(자극·과장 금지).
- 무단 상업용 BGM 금지 — 로열티 프리/자체 생성만, 출처 표기 필수.
- AI 음성·음악 생성 시 도구/라이선스 출처를 메타데이터에 남긴다.
- ko만 생성, en은 자리만(02 영어 대본 완성 후 대응).
- TTS 음성·BGM은 생성 에셋이므로 **출처 대장(08)에서 제외** — 웹 내 표기로만 관리.

---

## 6. 출력 형식 (JSON 스키마)

아래 값은 전부 예시(플레이스홀더)다. 실제 실행 시 카드·원고 내용에 맞게 채워진다.

```json
{
  "location_id": "{장소_식별자}",
  "narration": {
    "lang": "ko",
    "path": "output/{location_id}/audio/narration-ko.mp3",
    "source": "AI TTS ({도구명})",
    "is_ai_generated": true,
    "tone": "차분·객관",
    "en": null
  },
  "bgm": {
    "path": "output/{location_id}/audio/bgm.mp3",
    "license": "{royalty-free | self-generated}",
    "source": "{생성 도구/라이선스 출처}",
    "volume_relative_to_narration": 0.25
  },
  "pronunciation_dict": [
    {"term": "{원고에서 추출한 용어}", "reading": "{발음 표기}"}
  ],
  "sync_timeline": [
    {"segment_id": "{intro|development|closing|...}", "start_sec": 0.0, "end_sec": 0.0, "text_ref": "story.{segment}.ko"}
  ],
  "web_asset_package": {
    "player_block": "audio",
    "files": ["{narration 경로}", "{bgm 경로}"],
    "notes": "05-assemble 오디오 플레이어 블록에 즉시 연동"
  }
}
```

- `story`가 비면 `narration`/`sync_timeline`을 빈 값으로 두고 지어내지 않는다.

---

## 7. 성공 기준

- [ ] 원고가 발음 사전이 적용된 정확한 발음으로 읽힌다
- [ ] 낭독 톤이 차분·객관적이다(과장 없음)
- [ ] BGM이 로열티 프리/자체 생성이고 라이선스·출처가 표기됐다
- [ ] BGM 음량이 낭독보다 낮아 음성이 명료하다
- [ ] 싱크 타임라인이 최소 문단 단위로 제공된다
- [ ] 원고에 없는 문장이 낭독에 추가되지 않았다
- [ ] 원고의 병기(충돌) 부분이 낭독에서도 병기됐다
- [ ] `story`가 비었을 때 억지로 음성을 만들지 않았다(방어적 처리)
- [ ] 출력 JSON이 05 오디오 플레이어에 즉시 연동된다
- [ ] **(중요) 다른 유적지 카드로 실행해도 위 기준을 동일하게 만족한다** — 특정 장소에서만 통하는 규칙(발음 사전 하드코딩 등)이 섞이지 않았는지 최종 점검
